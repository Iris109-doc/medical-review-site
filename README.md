# medical-review-site · 知序

独立、无第三方前端依赖的医学复习知识库。数据与界面分离，学习记录保存在浏览器 IndexedDB，不需要账户、云数据库或API密钥。不自动上传任何内容。

## 启动与预览

需要 Node.js 18+，无需 npm install：

```sh
cd /workspace/medical-review-site
npm start
```

本地开发默认监听4173端口；可用 `PORT=8080 npm start` 更改端口。通过运行环境提供的端口预览入口打开4173端口；本机运行可在浏览器访问该端口。主项目的 index.html 不应直接双击打开，它需要HTTP来源加载JSON。另有通过 node build-preview.mjs 生成的 medical-review-preview.html 单文件快照，可下载后尝试用浏览器打开交互预览；已验证经HTTP服务打开。当前环境策略禁止file协议，未验证本地直接打开；若浏览器限制文件来源，请使用HTTP服务。单文件快照有独立的来源空间，与主网站的学习记录不自动共享，可通过JSON导入导出迁移。更新数据后运行 node build-preview.mjs 重建快照。平板需能访问运行服务的主机，记录按浏览器、协议、主机和端口隔离。

本项目未配置离线缓存。已经加载的页面交互无远端API依赖，但完全离线重新打开仍需可访问的网站服务。系统不自动执行网页部署或GitHub上传。

### 皮肤肿瘤 v1

新增稳定课程ID `derm-skin-tumors`、revision 1；16个知识条目、100道单选（100个不同考点）、12道简答和唯一10行卡片。保留原三门课程数据对象及revision，原独立课程包不变。条目、卡片、题目有稳定ID，后续内容变化需提升课程revision。

范围：脂溢性角化病与日光性角化病、鲍温病与浸润性SCC、角化棘皮瘤/皮角、BCC、三类色素痣、黑素瘤警示/四型/检查和处理原则、蕈样肉芽肿。每题均含答案、解析或参考要点、原知识点关联及来源页码；选项位置按固定种子打散，A/B/C/D各25题。题目按不同教学目标原创，非课件原题，不用个人回答生成公开作答记录。

来源为《3.皮肤肿瘤.pptx》67张幻灯片和《皮肤肿瘤.pdf》7页笔记，页码均从1起算；PPT引用的是幻灯片序号。仅发布来源元数据，不发布原文件或图片。未读取的超限带教PDF不列入来源。课件关于原位癌深度、黑素瘤旧预后比例、普通痣一律早切除、摩擦因果，以及活检和特殊部位治疗的必要纠正／补充在对应条目中标明。相关页码定位原课件，不代表补充均来自原文；本轮未独立在线核验现行指南，未作医学专家审校，不提供具体个体剂量、固定切缘或统一治疗方案。

**已有浏览器请先导出完整备份，再在“数据与设置”导入 [皮肤肿瘤 v1 课程JSON](data/skin-tumors-v1.json)。** 新增课程不会清除原三门课的作答、阅读、自评和卡片记录；服务器更新不会静默覆盖已有IndexedDB。相同版本同内容重复导入跳过，同版本冲突拒绝，旧版本不会覆盖新版本。将来提升本课revision时，仅本课旧版本作答按现有规则移除，其他课程保留，因此升级前仍须备份。全新浏览器直接载入当前四门课程。

公开内容只含课程知识、题库、参考答案、卡片和来源；无个人回答、成绩、错题、聊天、原始课件、患者可识别信息或浏览器备份。所有新增条目不预标个人薄弱点，卡片不含个人星标。

### 自身免疫性皮肤病 v1

## 使用

1. 系统知识库：按学科、章节、课程筛选，搜索标题、摘要和表格内容；标记已读。
2. 卡片：每课程一张表格，逐行或整张翻转，记录完成速览。
3. 题库：单选先选择再提交并查看解析；仅展开解析不记成绩。简答先输入再对照参考、自评。支持未答、当前错题、历史薄弱重点筛选和原知识点跳转。
4. 薄弱点：显示每题最新作答、错误列表、阅读进度和手动模块自评。重答正确后移出当前错题，但作答历史仍保留。简答自评与单选自动评分会明确区分。
5. 设置：导出完整JSON备份；在另一浏览器导入可恢复课程与进度。不要依赖浏览器缓存永久保存，清除站点数据会删除本地记录。

不从聊天导入或预填个人成绩；练习记录仅来自当前浏览器实际操作。新增课程不预标个人薄弱点。

## 内容与增量更新

`data/courses.json` 是初始课程JSON，结构如下；完整可工作的样例就是当前数据文件。

```json
{
  "schemaVersion": 1,
  "kind": "medical-review-content",
  "courses": [{
    "id": "stable-course-id",
    "revision": 1,
    "title": "课程标题",
    "discipline": "学科",
    "chapters": ["章节"],
    "confirmed": true,
    "sources": [{"id":"ppt","title":"课件.pdf","pages":67}],
    "nodes": [],
    "card": {"id":"stable-card-id","title":"一张卡，回看整节课","rows":[]},
    "questions": []
  }]
}
```

以上仅为结构示意，导入前必须填充完整条目、唯一卡片和至少100道单选及简答。模型中的 `validateCourses` 是可执行校验规则；来源页码必须在范围内，题目必须关联已有nodeId。文字按纯文本渲染，不执行导入的HTML或脚本。

- 课程ID、条目ID及题目ID保持稳定；同一课程重复ID、规范化后重复题干会被拒绝。
- 同课程同版本相同内容跳过，**同版本内容冲突拒绝**；提升revision才更新。旧版本导入不会覆盖新版本。
- 导入前可看到新增、更新和跳过数量；一次事务保存，验证或写入失败不部分覆盖。
- 更新课程版本会移除该课程旧版答题记录，以免旧答案套用新题；其他课程及自评、阅读状态继续保留（条目被删除而仍有记录时会拒绝导入，需显式迁移备份数据）。**更新前请导出完整备份。**
- 相同备份按作答ID去重；不同设备的记录合并，掌握度等标记以导入值覆盖同键。
- 导入上限20MB，100门课程，10万条答题记录。
- 已用浏览器优先载入IndexedDB内容，不会因磁盘JSON变更静默覆盖。更新JSON后通过设置导入，或在全新浏览器首次加载。

## 后续课程工作流

`medical-review` Skill副本位于 `.agents/skills/medical-review/`：上传新PPT → 完成60分钟复习、简答和至少20道单选 → 审阅唯一卡片 → **用户明确确认收录** → 编写对应JSON、扩展到至少100道单选与适量简答 → 校验 → 合并或导入同一网站。

确认前不擅自新增课程，不将未经确认的聊天内容写入知识库。只更新本地项目；提交、推送与部署需独立明确指令。
